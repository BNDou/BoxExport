# 病案卷内目录批量生成工具

## 背景
档案馆在接收医院病案室已归档且电子成像的旧病历时，需要病案室提供每个装箱病案的详细清单，而且对清单格式有明确要求。传统做法需要手工整理、复制粘贴、调整格式，工作量大、容易出错。该工具使用 Python 批量处理，自动从同结构的 Excel 源表读取数据，按要求生成对应的清单，显著降低工作量与出错率。

## 功能概述
- 图形界面（Tkinter），窗口固定在屏幕左上角 (0,0)。
- 选择数据源文件夹（如 `data/`），其中包含多个 `.XLS` 文件，结构一致。
- 支持导出格式选择：Excel `.xlsx` 或 PDF 格式，**默认 PDF**。
- 自定义导出目录（可通过"打开导出目录"按钮在资源管理器中查看）。
- 为每个源文件生成一份对应的清单 `.xlsx` 或 `.pdf` 到所选导出目录。
- 清单格式自动设置：标题、合并单元格、字体字号、行高、列宽、边框等。
- 读取列：病案号、出院科室、患者姓名、出院日期、入院日期、成像张数。
- **日期格式**：出院日期与入院日期统一为 `YYYYMMDD` 格式（无分隔符，如 `20150101`），去除所有时间部分。
- **重复案卷号合并**：同一文件内相同病案号的多条记录自动合并为一条——入院日期取最小值、出院日期取最大值、成像张数取总和。
- **出院科室合并**：合并时若出院科室相同则输出全称；若不同则输出各科室简写并用中文顿号「、」连接（如"普一、骨二"）。
- 支持"顺序号"连续编号：首次运行需输入起始值，之后按文件顺序递增。
- 实时进度：进度条、百分比、当前文件、每文件耗时、平均耗时、ETA。
- 支持"停止"按钮：点击后会在当前文件处理完成后终止后续文件。

## 环境与依赖
- Python 3.8+（Windows 10 测试通过）
- 依赖包：
  - xlrd==1.2.0（读取 .xls）
  - openpyxl（生成 .xlsx）
  - reportlab（生成 .pdf）

安装依赖：
```bash
pip install xlrd==1.2.0 openpyxl reportlab
```

## 字体配置（PDF 导出）
PDF 导出功能支持自定义中文字体，字体加载优先级如下：
1. **项目字体**（推荐）：将字体文件放入 `fonts/` 目录
   - MiSans-Normal.ttf（普通字体）
   - MiSans-Demibold.ttf（粗体字体）
2. **系统字体**：自动使用 Windows 系统字体
   - 微软雅黑（优先）
   - 黑体（备选）
3. **默认字体**：如果以上都没有，使用 PDF 默认字体

字体目录结构：
```
BoxExport/
  fonts/
    MiSans-Normal.ttf  (可选)
    MiSans-Demibold.ttf    (可选)
```

## 使用步骤
1. 运行 `BoxExport.py`（启动 GUI）。
2. 选择“数据目录”（建议为项目下的 `data/`）。
3. 设置“导出目录”（可点击“打开导出目录”按钮直接查看）。
4. 输入“起始顺序号”（如首次为 1；若承接上一批，请输入上次最后一个顺序号+1）。
5. 选择导出格式（默认 PDF，也可切换为 Excel）。
6. 点击“开始”，等待进度完成（界面显示当前文件、耗时与 ETA）。
7. 如需中止，点击“停止”（会在当前文件完成后停止后续处理）。
8. 处理完成后，生成的 `.xlsx` 或 `.pdf` 文件在所选"导出目录"。

## 源数据格式要求（.XLS）
- 表结构统一，取值列（以列字母说明）：
  - A：归档号（不导出）
  - C：病案号
  - D：出院科室
  - E：患者姓名
  - F：出院日期
  - G：入院日期
  - H：成像张数
  - I：备注（不导出，但目标表保留备注列）
- 默认从第3行起为数据行（第2行为表头）。

## 导出清单格式

### Excel 格式（.xlsx）
- A1-H1 合并，内容"案卷目录"，Microsoft YaHei UI 20 号，加粗，行高 25。
- E2"全宗号"、F2"120"、G2"类目"、H2"BL"，Microsoft YaHei UI 16 号，行高 25。
- G3"箱号"、H3为文件名对应的箱号（去掉前导 0），Microsoft YaHei UI 16 号，行高 25。
- 第4行表头（A-H）：
  - A"顺序号"（数据列居中显示）
  - B"案卷号（病案号）"
  - C"出院科室"
  - D"患者姓名"
  - E"出院日期"
  - F"入院日期"
  - G"成像张数"（数据列居中）
  - H"备注"（保留，不自动填）
- 列宽：A=9，B=13，C=13，D=8，E=12，F=12，G=8，H=13。
- 整表（A1 到 H最后行）添加细边框。
- 日期统一输出为 `YYYYMMDD` 格式字符串（如 `20150101`）。

### PDF 格式（.pdf）
- 使用 A4 纸张大小，格式完全匹配 Excel 版本。
- 相同的内容布局：案卷目录标题、全宗号信息、箱号信息。
- 相同的表头和数据格式，包含中文字体支持。
- 自动调整页面边距以容纳更多内容。
- 完整的表格边框和居中对齐。
- 日期统一输出为 `YYYYMMDD` 格式字符串。

## 重复案卷号合并处理

读取每个 XLS 文件的记录后，程序会自动对**同一文件内**相同病案号的多条记录进行合并，合并规则：

| 字段 | 合并规则 |
|------|---------|
| 入院日期 | 取所有记录中的**最小值**（最早日期） |
| 出院日期 | 取所有记录中的**最大值**（最晚日期） |
| 成像张数 | 取所有记录的**总和** |
| 出院科室 | 见下方科室合并规则 |
| 患者姓名 | 取第一条记录的值 |

合并后记录按病案号首次出现的顺序排列。单条记录（无重复）保持原样。

### 出院科室合并规则

- **所有记录科室相同** → 输出该科室全称（如"骨科一病区"）
- **存在不同科室** → 输出各科室**简写**，用中文顿号「、」连接（如"普一、骨二"）
- 未知科室（不在映射表中）→ 保持原值参与连接

内置 34 条科室简写映射，示例如下：

| 全称 | 简写 | 全称 | 简写 |
|------|------|------|------|
| ICU二病区 | ICU二 | 普通外科一病区 | 普一 |
| 呼吸内科病区 | 呼 | 普通外科二病区 | 普二 |
| 心血管内科病区 | 心内 | 普通外科三病区 | 普三 |
| 神经内科病区 | 神内 | 骨科一病区 | 骨一 |
| 神经外科病区 | 神外 | 骨科二病区 | 骨二 |
| 血液内科病区 | 血内 | 骨科三病区 | 骨三 |
| 血管外科病区 | 血外 | 泌尿外科病区 | 泌外 |
| 重症医学科 | 重 | 急诊医学科病区 | 急诊医学 |

> 完整映射表见 `BoxExport.py` 中的 `DEPARTMENT_ABBR_MAP` 常量。如需新增科室，直接在该字典中添加即可。

## 常见问题
- 无法读取 .xls：确保安装 `xlrd==1.2.0`（新版 xlrd 不再支持 .xls）。
- **日期格式**：程序自动将日期统一转换为 `YYYYMMDD` 格式（无分隔符），如 `2015-01-01` → `20150101`，适用于 Excel 和 PDF 导出。
- **重复案卷号**：同一文件内相同病案号的记录会自动合并（入院取最早、出院取最晚、张数取总和），无需手动去重。
- **科室合并**：合并后若科室不同会输出简写顿号连接，如需补充映射在 `DEPARTMENT_ABBR_MAP` 中添加。
- 顺序号从哪里开始：首次运行由用户输入；若需承接历史批次，可以输入上次最后一个顺序号+1。
- PDF 字体显示问题：
  - 如果 PDF 中文显示异常，可以将 MiSans-Normal.ttf 和 MiSans-Demibold.ttf 字体文件放入 `fonts/` 目录
  - 如果 `fonts/` 目录不存在，程序会自动使用系统字体（微软雅黑、黑体）
  - 确保系统已安装中文字体支持

## 目录结构示例
```
BoxExport/
  BoxExport.py
  README.md
  data/
    000001.XLS
    000002.XLS
    ...
  fonts/  (可选字体目录)
    MiSans-Normal.ttf  (普通字体)
    MiSans-Demibold.ttf    (粗体字体)

    000001.xlsx  (或 .pdf)
    000002.xlsx  (或 .pdf)
```

注：
- 导出目录可自定义，支持选择其他目录（如 D:/Exports/BoxExport/...）
- fonts/ 目录为可选，用于自定义 PDF 字体
